# Contributing

This project is in early development. Contributions are welcome, especially around:

- local pose-estimation backends
- benchmark reproducibility
- hardware-specific acceleration
- movement-feature extraction
- privacy-preserving data handling
- test fixtures and documentation

## Principles

1. Keep the default path local-first.
2. Avoid medical or diagnostic claims.
3. Prefer measurable, explainable behavior.
4. Document hardware/runtime assumptions.
5. Include tests or reproducible steps with implementation changes.

Before a large change, open an issue describing the proposed approach.
