# Hardware Support & Sponsorship

Privacy PT Coach is an open-source experiment in local computer vision for movement coaching.

## What I am looking for

The most useful support is **hardware access**, not cash:

- GPU development unit
- loaner system
- refurbished workstation
- compact AI PC
- edge AI device
- cloud compute credits
- substantial developer discount

## What the project can provide

For hardware that becomes part of the test matrix, I intend to publish:

- exact hardware and software configuration
- reproducible setup instructions
- latency / throughput measurements
- memory-use measurements
- implementation notes
- limitations and compatibility issues
- source code for the benchmark path

Support does **not** purchase a positive review or predetermined result. Results should remain reproducible and technically honest.

## Current areas of interest

- NVIDIA CUDA / TensorRT
- AMD GPU and Ryzen AI runtimes
- Apple Silicon local inference
- edge AI accelerators
- high-memory local AI systems

Open a GitHub issue titled **Hardware support** or contact the maintainer through the public contact information on the maintainer's GitHub profile.
